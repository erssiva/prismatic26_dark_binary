🎯 PROJECT OVERVIEW

This is a complete implementation of an AI-powered workflow generation system that
converts user goals into structured, actionable step-by-step workflows with 
recommended tools and technologies.

Key Concept:
  User Goal → AI Analysis → Structured Workflow → Tool Recommendations
  
Example:
  "Build a plant disease detection app"
  ↓
  [5-8 steps with tools, effort estimates, and dependencies]
  ↓
  "Define Requirements", "Data Collection", "Model Development", etc.

🔌 API ENDPOINTS REFERENCE

Health Check
────────────────────────────────
GET http://localhost:8000/
Returns: {message, version, status}

Generate Workflow (Main Endpoint)
────────────────────────────────
POST http://localhost:8000/generate-workflow/
Body: {goal: "string", context: "string or null"}
Returns: {goal, total_steps, steps[], overall_tools[]}

Example curl command:
curl -X POST http://localhost:8000/generate-workflow/ \
  -H "Content-Type: application/json" \
  -d '{"goal": "Build an ML app"}'

Refine Step Details
────────────────────────────────
POST http://localhost:8000/refine-step/
Body: {step_task: "string", suggestions: true/false}

Get Available Tools
────────────────────────────────
GET http://localhost:8000/tools/
Returns: {available_tools[], tool_categories{}}

Get Example Workflows
────────────────────────────────
GET http://localhost:8000/examples/
Returns: {examples[]}

──────────────

Frontend Stack:
──────────────

• CSS3 - Styling (Grid, Flexbox, Animations)
• Vanilla JavaScript - Interactivity (no dependencies)
• Fetch API - HTTP requests

Data Models:
──────────────
WorkflowStep:
  • step_number: int
  • task: str
  • description: str
  • tools: List[str]
  • estimated_effort: str
  • dependencies: List[int]

WorkflowResponse:
  • goal: str
  • total_steps: int
  • steps: List[WorkflowStep]
  • overall_tools: List[str]

📞 TROUBLESHOOTING QUICK GUIDE

Problem: "Cannot reach server"
Solution: Ensure python run_server.py is running in another terminal

Problem: "Port 8000 already in use"
Solution: Kill existing process or change port in run_server.py to 8001

Problem: "Slow first request"
Solution: Normal - AI model loads (~2-3 min on first launch)

Problem: "No workflows generated"
Solution: Check browser console (F12) for CORS or API errors
