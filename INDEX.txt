❓ FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════

Q: How do I start using the system?
A: Follow the "Quick Start in 3 Steps" section above.

Q: Why is the first request slow?
A: The AI model must load into memory (2-3 minutes). This only happens 
   once when the server starts.

Q: Can I use this in production?
A: The code is production-ready for local deployment. For cloud 
   deployment, add database support and environment configuration.

Q: What if the workflow generation fails?
A: A default 5-step fallback workflow will be provided automatically.

Q: Can I modify the tools or effort estimates?
A: Yes! Edit the TOOL_MAPPING and estimate_effort() function in main.py

Q: Is this open source?
A: Yes, all code is provided. You can modify and extend it.

🆘 TROUBLESHOOTING QUICK_REF
═══════════════════════════════════════════════════════════════════════════

Error: "Cannot reach server"
Fix: Ensure "python run_server.py" is running in another terminal

Error: "Port 8000 already in use"
Fix: Kill the process or change port to 8001 in run_server.py

Error: "Module not found"
Fix: Run "pip install -r requirements.txt"

Error: "Slow response"
Fix: Normal on first request. Wait 2-3 minutes for model to load.

Error: "No workflows appearing"
Fix: Check browser console (F12) for errors
